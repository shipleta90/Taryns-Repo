# Taryn Cardona — Consulting Website

A simple static one-page site for launching independent operations consulting work.

## Structure

- `index.html` — page content
- `css/styles.css` — styling
- `js/main.js` — small footer-year script

No build step, no dependencies. Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deploying (free options)

**GitHub Pages**
1. Push this repo to GitHub (already done if you're reading this from the repo).
2. In repo Settings → Pages, set the source branch to `main` (or your default branch) and folder to `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo-name>/`.

**Netlify**
1. Drag-and-drop this folder into [Netlify Drop](https://app.netlify.com/drop), or connect the GitHub repo for auto-deploys on push.

Both are free and give you an HTTPS URL immediately; a custom domain can be added later on either platform.
